# AI-Supported AMI Clinical Reasoning Intervention in Undergraduate Nursing Education

## Project Overview

This repository provides methodological and reproducibility materials for the AI-supported clinical reasoning intervention implemented in the study:

**"Enhancing Undergraduate Nursing Students' Digital Feedback Literacy and AMI Learning Retention by Using Artificial Intelligence."**

The intervention was designed to support undergraduate nursing students in developing clinical reasoning skills related to Acute Myocardial Infarction (AMI), while enhancing their ability to engage with and learn from digital feedback.

## Intervention Implementation

The intervention was delivered through a browser-accessed **Custom GPT**, configured using the standard ChatGPT GPT Builder interface.

The Custom GPT served as an AI-supported educational environment in which students could interact with simulated clinical scenarios, receive AI-generated responses, and engage in structured clinical reasoning activities.

The intervention consisted of six 90-minute educational sessions. Each session included:

- 60 minutes of shared AMI educational content based on relevant clinical guidelines.
- 30 minutes of AI-supported clinical reasoning activities using the configured Custom GPT.

Students accessed the configured GPT through their web browsers during the intervention sessions.

## Technical Configuration and Access

The educational environment was established using the standard Custom GPT configuration workflow.

The repository documents the configuration and implementation procedures required to reconstruct the educational intervention.

Importantly, this repository does **not** contain the proprietary source code of ChatGPT, OpenAI's underlying models, or the internal software infrastructure of OpenAI. The intervention was implemented using the available ChatGPT Custom GPT configuration interface rather than a separately developed AI model.

## Reproducibility

These materials are intended to support methodological transparency and facilitate the reconstruction of the educational intervention by other researchers and nursing educators.

Researchers seeking to reproduce the intervention should consider the availability of ChatGPT Custom GPT functionality, account-level access requirements, and potential changes in the platform's interface or underlying AI models over time.

The repository documents the intervention configuration and educational procedures rather than providing an independent executable software application.

## Relationship to the Published Study

This repository accompanies the research manuscript submitted to *Scientific Reports* and provides supplementary methodological documentation addressing the intervention's technical implementation and reproducibility.

The repository is intended to complement the information reported in the manuscript and its supplementary materials.

## Transparency Statement

The authors distinguish between the educational intervention configuration and the proprietary infrastructure of the underlying AI platform. No claim is made that the source code of ChatGPT or OpenAI's proprietary systems is included in this repository.
